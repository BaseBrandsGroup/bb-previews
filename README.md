# Base Brands previews

Temporary hosting for client approval links (landing pages, calculators, funnels) before they go live in Growth Engine.

- One folder per client project, e.g. `frequency-10k-gap/`. The folder's `index.html` is the page clients open.
- Link format: `https://<github-username>.github.io/bb-previews/<folder>/`
- Every page has `noindex, nofollow` and `robots.txt` blocks search engines. The site is still public to anyone with the link, so don't put client data, logins or live forms here.
- Remove a folder once the page is live in GHL.
