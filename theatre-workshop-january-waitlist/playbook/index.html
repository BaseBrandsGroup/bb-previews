3 · What we need from you

Get these ready first

  • Space numbers for each class in January
  • Photos: one big stage shot (e.g. Town Hall), plus one per class
  • 3 short parent quotes (first name and child's age)
  • A 60-second welcome video of you in the studio. A phone is fine.
  • Your logo file
  • Pebble trial booking links for each class
  • WordPress login for Base Brands
  • Confirmation from your web developer that the Meta Pixel is installed

4 · Building it

Two pages on your WordPress site

  1. Waitlist pages: one for Birmingham, one for Bromsgrove, matching your site's black, pink and Mulish font.
  2. Form: parent name, email, mobile, child's name and age, and class. When it's sent, parents land on the thank-you page.
  3. Thank-you page: confirms their spot. This is also where Meta counts a lead, so the ads learn who to show to.
  4. Where sign-ups go: Pebble can't send automatic emails, so the form connects to an email system that can. Growth Engine (the system Louise uses) does this, and it tags each parent by location and class.
Before the ads go live, we'll send a test sign-up and check it arrives, gets tagged and receives Email 1.
